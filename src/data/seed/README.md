# Seed data — placeholder, not real

`nfl-players-2026-placeholder.json` is **fake, generated data** (see `generate-seed.mjs`), used only to exercise the app during Phase 1 development. Names, teams, projections, ADP, and bye weeks are not real. Do not use for actual draft prep.

Regenerate with:

```
node src/data/seed/generate-seed.mjs > src/data/seed/nfl-players-2026-placeholder.json
```
